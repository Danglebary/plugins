# New default reviewers don't reach already-set-up repos

From ticket 005's refactor pass (dx-expert). A newly-shipped always-on reviewer (like `standards-reviewer`) reaches a repo only on a *fresh* `/setup`. For every repo that already ran setup, it arrives only if the developer independently remembers to re-run setup in refresh mode. Two things make the gap silent:

- `/refactor` verifies that *listed* manifest agents resolve (and refuses if not), but never checks whether a shipped default is *missing* from the manifest — so an updated-plugin repo runs its refactor pass without the standards lens, presented as complete.
- The plugin README labels setup "once per repo," which actively discourages the refresh that would deliver the reviewer.

So "Always included regardless of repo content" is true for fresh setups and quietly false for every existing repo. Fix shape when promoted (design fresh): give the delivery a push signal instead of relying on recall — e.g. `/refactor` diffs the manifest's always-on section against the plugin's current default set and nudges ("`standards-reviewer` ships as a default but isn't in your manifest; re-run `/setup`"), and the README names the refresh-after-update trigger the setup skill already documents. This is a plugin-update-propagation concern broader than any one reviewer; the same gap will recur every time the default set grows. Changes neither the convergence merge nor the manifest format.

Related, same ticket (dx-expert), smaller: `/done` dispatches the close-out pair with no check that `spec-conformance` resolves to a registered agent — unlike `/refactor`, which refuses loudly on an unresolved manifest name. Ticket 005's retro recorded the real consequence: a mid-session-created agent isn't a registered dispatch type until reload, so the first `/done` ran the new agent's definition inlined into a generic agent — a silent degradation, not an error. Worth deciding whether `/done` should mirror the resolve-check (fail loud, name "reload the session" as the fix) when this is promoted.
