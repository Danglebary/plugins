# A persisted dispatch record cannot be attributed to the run that wrote it

From ticket 005's refactor pass (qa-engineer + software-architect, 2× convergence). `/refactor`'s step 9 resolves the interrupted-pass case with a presence test: *"if the ticket's entry already carries a `**Dispatch** (refactor):` line, the interrupted predecessor persisted its own and it stands."* But the same skill documents repeat passes over one ticket as a supported route — gate 3's decline says re-running it "runs a full new pass — manifest, diff, reviewer dispatch" — and each completed pass appends its own line. So a *second* pass interrupted before dispatch finds the *first* pass's line, concludes a record stands that was never its own, and writes nothing. That is the attestation-as-verification error the clause was written to prevent, reachable through the clause itself.

The deeper shape: the record is prose with no run identity, so the text cannot answer "which run wrote this." The clause needs a distinction the artifact cannot carry. Nor can any fixture verify the clause today — the state it must distinguish leaves no distinguishing mark, which is the same "infrastructure never observed failing" problem spec 006 exists to close, one layer up.

Directions, and they conflict. **Make the line self-identifying** — a run marker, a timestamp, or a pass ordinal (`**Dispatch** (refactor, pass 2):`) — which makes the presence test real and the interrupted case observable, at the cost of adding structure to a field `RETRO-FORMAT.md` deliberately left as prose on the argument that the record is an attestation nobody can audit anyway. **Or make the entry single-writer per keeper** — a second pass replaces rather than appends — which keeps the field prose-shaped but discards the first pass's coverage claim, and a pass that ran seven lenses is not equivalent to a later pass that ran seven again. **Or drop the presence test** and have an interrupted resume always state plainly that it cannot reconstruct its predecessor's record, which is honest, needs no format change, and costs a real record on every crash-and-resume.

Related but distinct from the banked `running-retro-heading-collides-with-recovery-discriminator` idea: same class (a discriminator keyed on a shape that does not discriminate), different artifact and different consumer.
