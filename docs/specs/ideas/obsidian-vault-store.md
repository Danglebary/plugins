# Obsidian-vault store

Let the Personal workflow keep its planning artifacts (specs, tickets, retros, Glossary, ADRs) in an Obsidian vault instead of in-repo markdown — the same files-on-disk medium, different root and conventions (vault lives outside the repo, wikilinks, possibly Obsidian properties). Expected shape per ADR 0003's re-entry path: a thin path-indirection layer plus link/naming conventions designed fresh at promotion time, not a resurrection of the removed notion resolver. Open questions when promoted: the git story for an out-of-repo vault (close-out commit gates assume planning artifacts are committable alongside code), link integrity between code references and vault notes, and whether mattpocock/skills' `obsidian-vault` skill (personal bucket) has borrowable conventions.
